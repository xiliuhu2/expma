# 三线穿阳 · 介入时机的指数状态条件回测（T+1 口径）

日期：2026-11-07（数据基准 2026-11-06 收盘）
起因：用户判断「三线穿阳是信号，但介入时机要看当时指数情况，变量因子要调整」。
方法：把每一次「再放量破信号日高」触发确认（现行买点，471 个事件，2025-11~2026-08）落到**触发日**的
上证指数状态上分桶回测（T+1 撮合：止盈/止损从买入次日起判，成本 0.25%），并对比三种介入变体与组合过滤。
脚本：`backtest/cross3_idx_timing.py`（可复跑）→ `backtest/cross3_idx_timing_result.json`

## 一、结论先行

**用户的判断成立**：触发日的指数状态对结果影响巨大，且方向清晰——

| 触发日指数状态 | n(全) | 胜率 | 均值（+2.5%/20日） |
|---|---|---|---|
| **上证量比 ≥1.1（放量日触发）** | 134 | **94.0%** | **+1.40%** |
| MA20 上方 且 量比≥1.1 | 125 | **94.4%** | **+1.41%** |
| MA20 上方 且 mom20 0~6（温和上行） | 266 | 89.8% | +0.70% |
| 上证 > MA20 | 352 | 87.8% | +0.19% |
| 全部（基准，现行规则） | 471 | 86.8% | **+0.01%** |
| 上证 < MA20（弱市触发） | 119 | 75.1% | -0.60% |
| 大盘跳空 ≥+1% 时触发 | 15 | 53.3% | -4.35% |
| 大盘跳空 ≤-1% 时触发 | 30 | 66.7% | -5.30% |
| mom20 ≥+6%（过热） | 220 | 73.2% | -1.19% |

三个最关键的**指数因子**（单因子，train/oos 双段方向一致）：

1. **指数量比**（触发日上证量 / 前5日均量）：≥1.1 时胜率 94.0%/均值 +1.40%，是全表最强因子——
   个股放量破高若发生在**大盘也放量**的日子，才是真突破；<0.9~1.1 的「缩量日」触发最差（76.1% / -0.49%）。
2. **距 MA20 位置**：-2~+2%（贴线）最平庸（78.8%）；**+2~+5%** 最好（83.7% / +0.58%）；
   但 mom20 ≥+6% 的过热段反而最差（73.2% / -1.19%）——**温和上行优于过热**。
3. **开盘缺口**：大盘跳空 ±1% 以上的日子触发，胜率 53~67%、均值 -4~-5%，**大跳空日不介入**。

## 二、介入时机变体（变量因子调整）——「等待」不如「过滤」

| 介入方式 | n | 胜率 | 均值（+2.5%/20日） |
|---|---|---|---|
| base（触发次日开盘买，现行） | 471 | 86.8% | +0.01% |
| **weak_skip（上证<MA20 不做）** | 352 | **87.8%** | **+0.19%** |
| wait_pull（等回踩 EMA12 收回再买） | 204 | 84.3% | **-0.67%** |
| wait_ma5（等指数回踩+个股再破高） | 139 | 84.2% | **-1.31%** |

**关键发现：两种「等回调再买」的介入都显著更差**——强势票触发后不回踩，能等到回踩的多是转弱的票
（选择偏差）。**正确的变量因子不是「换买点」，而是「用触发日指数状态过滤：弱市/缩量/跳空日不做」**。

## 三、推荐的新变量因子（供确认后落地到 p13/弹窗）

```
信号：三线穿阳 + A级（不变）
买点：再放量破信号日高（不变：收盘>信号日高 且 量比≥1.2）
新增介入过滤（触发日收盘判定，次日开盘买）：
  ① 上证 > MA20（弱市不做）                        119 个事件被剔除
  ② 上证量比 ≥0.9（缩量日不做，>=1.1 为佳）
  ③ 上证 20日涨幅 0~6%（过热 >6% 不做；深跌 <-6% 不做）
  ④ |上证开盘缺口| <1%（大跳空日不做）
退出（T+1）：+4% 止盈（训练段三个 X 中最优）/ 20日时间退出 / 无硬止损
```

**已落地（2026-11-07，用户确认「提醒当日还是要发出来」）**：
指数过滤只区分「可介入 / 仅观察」，**不静默**——

- `cross3_80win_today.py` 新增 `idx_gate()`：清单/持仓每行带 `idx_ok / idx_why / idx_detail`，整体带当日指数门；
- `win80_alert.py`：买入窗分两类，**两类当日都弹**——🟢红色「开盘买入」（指数配合）/ 🟡琥珀「确认但指数不配合（仅观察）」，
  文案注明回测依据与「不买也要知道它确认了」；
- p13：待确认表状态列显示 ✓指数配合·可介入 / △指数不配合·仅观察（悬停见具体未达标项），
  summary 与提醒面板显示当日指数门；日报 ⑪ 段同口径。

**过滤后推荐参数的表现（MA20上方 且 mom20 0~6，n=266）**：

| 退出 | train | oos | all |
|---|---|---|---|
| +2.5%/20日 | 89.7% / +0.67 | 92.9% / +1.21 | 89.8% / +0.70 |
| +3%/20日 | 88.1% / +0.84 | 92.9% / +1.68 | 88.3% / +0.89 |
| **+4%/20日** | **84.9% / +1.09** | **92.9% / +2.61** | **85.3% / +1.17** |
| +5%/20日 | 79.8% / +1.00 | 92.9% / +3.53 | 80.5% / +1.13 |

若再叠加量比≥1.1（n=125）：+4%/20日 达 **90.4% / +2.30**（train 90.2% / +2.28）——
胜率重回 90% 且训练段期望为正，**这是 T+1 修正后第一个双段健康的高胜率参数**。
样本外 n 偏小（2~14），结论以「因子方向 + 规则族稳健」背书，不是单点参数。

## 五、风险与限制

- 样本 9 个月、471 事件，指数条件分桶后部分格子 n<40（如量比≥1.1 的 oos 仅 8），存在小样本风险；
  「MA20上方+量比≥1.1」的 oos 只有 2 笔，**不能单独作为执行依据**，应视为「过滤方向正确」的证据。
- mom20 ≥6% 的 220 笔全部在训练段（26-02/05 过热期），oos 无覆盖，过热剔除的稳健性待前向验证。
- 分桶边界（1.1 / 0.9 / 6%）为网格搜索所得，存在轻微过拟合风险；核心结论（量比方向、弱市剔除、
  跳空剔除、等待变差）在多个邻域参数下方向一致。
- 指数量能来自 `indices/sh000001.json`（东财口径），与个股量能同源，无未来函数。

*历史数据挖掘结果，不构成投资建议；新过滤因子需用户确认后才落地到 p13 清单与买卖弹窗。*
