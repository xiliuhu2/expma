> 起因：用户指出「不一定要穿线当天或次日买入，穿阳是个信号」，并明确三线是 **EXPMA12 / EXPMA50 / 89 日均线**。
> 本轮把信号日 t0 与买入日解耦：t0 只负责给票打「三线转强」标签，之后 20 个交易日内寻找买点。

## 一、先确认三线口径（与用户描述一致）

| 线 | 代码定义 | 说明 |
|---|---|---|
| EXPMA12 | `ema(close, 12)`，`k = 2/(n+1)` 递归 | 标准指数移动平均，等价通达信 EXPMA(12) |
| EXPMA50 | `ema(close, 50)` | 同上 |
| 89 日均线 | `SMA(close, 89)` | **简单**移动平均，不是 EMA |

**三线穿阳判据**（`server.py: cross_lines`）：当日为阳线，且
`open < min(EXPMA12, EXPMA50, MA89)` 且 `close > max(EXPMA12, EXPMA50, MA89)`
——即**阳线实体把三条线全部包住**，比「昨收在下、今收在上」更严格。

## 二、思路重构：从「信号日买入」到「信号后找买点」

| | 前几轮（旧） | 本轮（新） |
|---|---|---|
| t0 三线穿阳 | = 入场日，t0+1 开盘买 | = **状态标记**，不交易 |
| 买点 | 固定 t0+1 | t0+1 ~ t0+20 内扫描买点触发器，取首次触发 |
| 成交 | 信号日次日开盘 | **触发确认日的次日开盘**（可实现、无未来函数） |
| 卖出 | +X% 止盈 / -Y% 止损 / N 日收盘退出 | 同左 |

撮合：往返成本 **0.25%/笔**；逐日先看 high/low，同日同时触及按**先止损**保守判定；未触发则第 20 日收盘平仓；high/low 只用于结果判定。所有触发器只用 j 及之前数据。

**样本**：因需 t0 之后完整 40 根（买点窗口 20 + 持有 20），可评估信号 **6749** 条，2025-11-24 ~ 2026-08-31；按 **2026-07-06** 切分，训练 5682 / 样本外 1067（A 级样本外仅 56 个）。

## 五、90%：第一次出现「样本外也正期望」，但站不住

`+1% 止盈 / 不止损 / 20 日` 口径下，训练段胜率≥90% 且正期望的组合有 **7 个**，全是「A 级族 + 某个买点」：

| 买点 × 过滤 | 训练 | 样本外 |
|---|---|---|
| 连 3 日站稳 MA89 + A 级+非涨停 | 96.6% / +0.29 (n=328) | 96.2% / **−0.01** (n=26) |
| 再放量破信号日高 + A 级 | 96.1% / +0.17 (n=434) | 94.6% / **+0.24** (n=37) |
| 再放量破信号日高 + A 级+粘合≤3% | 95.8% / +0.12 (n=312) | 94.7% / **+0.45** (n=19) |
| 回踩带内守 MA89 + A 级+非涨停 | 95.9% / +0.02 (n=342) | 96.7% / **+0.27** (n=30) |
| 其余 3 个 | 95.3~96.4% / +0.12~0.17 | 91.3~93.3% / **−0.06 ~ −0.63** |

**为什么仍不能宣布达成 90% 目标**（`cross3_entry_verify.py`）：

1. **样本量太小**：样本外 n=19~37，胜率 94.6% 的 Wilson 95% 置信下界只有 **82.3%**；「90%」在统计上不成立。
2. **成本一升就归零**：成本 0.25% → 0.35% → 0.50% 时，`再放量破高 +1%` 样本外均值 **+0.24 → +0.14 → −0.01**；`回踩带内守MA89 +1%` **+0.27 → +0.17 → +0.02**。
3. **换切分点就翻负**：以 2026-05-01 / 06-01 为样本外起点时，这批 90% 组合均值分别为 **−0.24 / −0.27**（再放量破高）与 **−0.68 / +0.33**（回踩带内），在 0 附近摆动。
4. **整体几乎不赚钱**：把「未触发买点 = 不交易 = 0 收益」计入后，每个 A 级信号平均只赚 **+0.14%（+1% 组合）/ +0.03%（回踩带内组合）**，而 +3% / +5% 组合是 +0.46% / +0.67%。

也就是说：**90% 的高胜率可以作为「入场纪律」实现，但它赚得极薄，对成本、市场环境极度敏感，不是可依赖的盈利策略。**

## 六、两个反直觉但重要的发现

### 1. 最优买点是「突破确认」，不是「回踩低吸」

纯回踩类（回踩三线带收回、缩量企稳）在全部信号上仍是**负期望**（−0.5%/笔左右）；表现最好的是 `再放量突破信号日高点`——它筛掉的是「穿阳之后就不涨」的伪信号。回踩常常是趋势走弱的开始，而不是低吸机会。

### 2. 买点的价值是「过滤」，不是「买得更便宜」

配对比较（同一信号内，买点收益 − T+1 旧基线收益，+3% 规则）：所有买点平均差 **−0.09 ~ −2.54pp**，跑赢基线占比仅 2.8%~22.4%，中位差 0。原因是 +3% 止盈下，只要触及止盈两者都赚 +2.75%，而**早买更容易在 20 日窗口内摸到 +3%**。所以「等确认」提高的是**入场选择性**（只在确认发生时才买），代价是入场价更高。覆盖率调整后「只在破高确认时入场」每信号 +0.46%（入场率 79.3%），略优于「全部 T+1 追入」的 +0.43%（100%），+5% 版本 +0.67% 更优——**优势来自少做了 20% 的差单，而不是买得便宜**。

### 3. 参数邻域平滑（买点后移让规则更健康）

样本外，同一「再放量破高 + A 级」买点下把止盈从 +1% 调到 +5%：

| 止盈 | +1% | +1.5% | +2% | +3% | +5% |
|---|---|---|---|---|---|
| 胜率 | 94.6% | 94.6% | 94.6% | 91.9% | 86.5% |
| 均值 | +0.24 | +0.72 | +1.19 | +1.51 | +2.61 |

单调、平滑，没有孤岛式最优点。对照「T+1 追入 + A 级」：`91.1%/−0.43 → 87.5%/−0.39 → 85.7%/−0.04 → 78.6%/+0.34 → 62.5%/−0.30`，乱跳且多为负。持有期 10/15/20 日 likewise：新买点 89.2%/+1.55、91.9%/+1.61、91.9%/+1.51，旧基线 71.4%/−0.03、76.8%/+0.23、78.6%/+0.34。**这是「信号 ≠ 买点」最有说服力的证据。**

## 七、最终交付规则（本轮推荐，取代上一轮的 T+1 追入）

```
状态标记 t0：三线穿阳（阳线实体包住 EXPMA12 / EXPMA50 / MA89）
质量过滤：t0 收盘破 20 日高 + MA89 十日斜率 > 0        （= 现有 A 级形态）
买点确认：t0 之后 20 日内，某日 收盘 > t0 最高价 且 量比 ≥ 1.2
买入：确认日次日开盘
止盈：盘中触及买入价 +3%（胜率优先）或 +5%（期望优先）立即卖出
止损：不设个股硬止损，靠小仓位分散 + 组合总回撤线
时间退出：第 20 个交易日收盘无条件平仓
```

| 版本 | 训练段 | 样本外 | 覆盖率调整后每信号 |
|---|---|---|---|
| **A · +3% 止盈** | 86.4% / +0.50% (n=434) | **91.9% / +1.51%** (n=37) | +0.46% |
| **B · +5% 止盈** | 77.6% / +0.69% (n=434) | **86.5% / +2.61%** (n=37) | **+0.67%** |
| 对照：旧交付 T+1 追入 +3% | 86.8% / +0.44% | 78.6% / +0.34% | +0.43% |

B 期望更厚、对成本更稳（0.5% 成本下样本外仍 +2.36）；A 胜率更高。两者参数邻域都平滑，可按偏好选一个，**不要混用**。

## 九、风险与局限（必须说清）

1. **样本外太短**：切分后仅约 2 个月、A 级样本外 56 个、买点触发后 37 个；91.9% 胜率的 Wilson 95% 下界仅 78.7%。
2. **强依赖市场环境**：换 2026-05-01 / 06-01 为样本外起点，A 组合均值为 **−1.05 / −0.21**，B 组合 **−1.38 / +0.22**；所有组合在 5~6 月都亏，7 月后才转正。当前 regime 下行、情绪退潮 32.9°，属不利环境，按纪律应轻仓。
3. **尾部风险**：A 组合样本外 P05 **−12.26%**、最差 **−20.37%**；加 −8% 硬止损在上一轮已证明会把期望打负。实盘靠分散而非单票死扛。
4. **突破确认可能跳空**：收盘确认 + 次日开盘买，若次日大幅高开，实际成交价会明显高于回测基准。
5. 数据为本地约 1 年、320 根前复权日 K，含幸存者偏差；未计涨跌停无法成交、停牌、冲击成本变化。
