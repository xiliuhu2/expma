# 三线穿阳 · 高胜率选股策略深挖报告（2026-11-06 收盘）

> 目标：找到胜率 90% 的选股策略。结论先行：**90% 找到了，但「90% 胜率 + 正期望 + 样本外稳定」三者在这批信号上不可兼得**；真正可交易的稳健折中是 **A 级过滤 + 3% 止盈 / 不设硬止损 / 20 日时间退出：训练 86.8%、样本外 80.5% 胜率，两段都正期望**。

---

## 一、数据与口径（所有结果可复跑）

| 项目 | 设定 |
|---|---|
| 信号 | 全市场全历史「三线穿阳」（阳线实体同时包住 EXPMA12 / EMA50 / MA89），2025-11-24 ~ 2026-11-06 |
| 样本 | `webapp/tltrack/signals.csv` 共 **9046** 条；需完整 20 日盘中路径的可评估样本 **7919** 条（至 2026-10-09） |
| 买入 | **信号日次日开盘价**（信号日收盘买不到），扣 **0.25%/笔** 往返成本（佣金+印花税+一档滑点近似） |
| 卖出 | 盘中最高价触及 +X% 止盈 / 最低价触及 -Y% 止损（同日同时触及按**先止损**保守判定）/ N 日收盘时间退出 |
| 两种胜率 | ①**严格胜率** = 买入 → 5 日收盘 > 0（与日报一致）；②**触达胜率** = 持有期内盘中曾触及止盈并卖出 |
| 防过拟合 | 按时间 **70/30 拆分**（切分日 **2026-07-06**）：训练 5682 / 样本外 2237；搜索只在训练段做 |
| 无未来函数 | 所有特征只用 t 及之前数据；high/low 仅用于结果判定 |

## 三、第一轮：严格胜率口径下 90% 不可能

`cross3_highwin_mining.py`：46 个信号日可得的二值条件（破20高 / MA89斜率 / 倍量 / 缩量 / 三线粘合 / 低位平台 / 市值 / 涨停 / 技术分 / 事件催化 / regime 等），位集穷举 2~3 条件共 **11340** 个组合。

| 口径 | 结果 |
|---|---|
| 全样本基线 | n=8679，5日胜率 **44.4%**，均值 -0.15%，超额 +0.34pp |
| 现有 A 级（破20高+MA89上行+上行regime） | n=413，**54.2%**，均值 +1.85% |
| 训练集最高（n≥100） | **66.4%**（MA89强上行>2 + regime上行 + 距EMA12<3%）→ **样本外仅 25.6%** |
| 训练集最高（n≥50 / n≥30） | 70.4% / 71.9% → 样本外样本均 <10，全部失效 |
| 训练集最高（n≥10） | **90.0%（n=10）** ← 这就是「90%」最容易达成的假象 |

**多重检验警示**：11340 次搜索下，即使信号完全无预测力，最高训练胜率也会被随机推到 65~70%；把样本降到 10 个，90% 唾手可得。所有训练 Top10 组合样本外全部衰减到 16.7%~55.6%。

## 四、第二轮：换真实交易口径，90% 稳稳出现——但稳稳亏钱

`cross3_touch_backtest.py`：100 组 止盈X% × 止损Y% × 持有N日 网格，次日开盘买入、盘中 high/low 触达判定。

| 规则 | 触达胜率 | 扣成本后单笔均值 | P05 | 最差 |
|---|---|---|---|---|
| **全部信号 +1%止盈 / 不止损 / 20日** | **90.4%（n=7919）** | **-0.51%** | -10.65% | -41.37% |
| +1% / -8% / 20日 | 86.4% | -0.42% | -8.25% | -8.25% |
| +3% / 不止损 / 20日 | 74.7% | -0.69% | -17.07% | -47.71% |
| +5% / 不止损 / 20日 | 61.9% | -0.85% | -19.23% | -48.98% |
| 网格内 100 组最优期望 | +7%/-3%/3日 胜率 17.0% | **-0.02%**（无一组正期望） | — | — |

**为什么 90% 反而亏钱**：90.4% 的交易赚 +0.75%（1% 止盈减成本），剩下 9.6% 不设止损一路持有，平均亏约 -12.5%，尾部到 -41%，把小赢全部吃光。这就是「在压路机前捡钢镚儿」。

**这个 90% 极其稳定**：训练 **90.5% / -0.51%**，样本外 **90.0% / -0.53%**（`cross3_robust.py`）。它是真实的统计规律，只是方向是亏的。

## 五、第三轮：90% + 正期望 —— 找到了，但样本外崩了

`cross3_frontier.py`：16 个过滤组合 × 75 组止盈止损 = 1350 个规则。

**全样本满足「胜率≥90% 且扣成本正期望」的 3 个**：

| 过滤 | 规则 | 胜率 | 均值 | n |
|---|---|---|---|---|
| A级 + 非涨停 + 粘合≤3% | +2%止盈 / 不止损 / 20日 | **91.3%** | +0.38% | 298 |
| A级 + 粘合≤3% | +2% / 不止损 / 20日 | 90.1% | +0.23% | 425 |
| A级（破20高+MA89上行） | +2% / 不止损 / 20日 | 90.9% | +0.21% | 615 |

**样本外检验（2026-07-06 后）**：

| 组合 | 训练 | 样本外 |
|---|---|---|
| A级+非涨停+粘合≤3%，+2%/不止损/20日 | 91.4% / +0.27% | **87.0% / -0.19%** |
| A级+非涨停+粘合≤3%，+5%/-8%/20日（全样本期望最高 +1.30%） | 73.0% / +1.62% | **37.5% / -2.36%（n=24）** |
| 全部信号 +1%/不止损/20日 | 90.5% / -0.51% | 90.0% / -0.53% |

「90% 俱乐部」全部 10 个训练胜率≥90% 的规则，样本外胜率仍高达 87~92.5%，**但均值无一例外为负（-0.19% ~ -0.80%）**。唯一带正期望的 A级+2%/不止损/20日，样本外也转负。

**理想化让步检验**：即使把成本降到 0、允许信号日收盘价买入（现实中买不到），A级 +1%止盈/不止损/20日 训练 94.4%/+0.03%、样本外 87.0%/-1.01% —— **90% 与稳定正期望依然不可兼得**。

## 六、最终交付：稳健的高胜率 + 正期望策略

`cross3_robust.py` 以「训练段与样本外**同时**胜率≥55%、均值>0」为硬标准，378 个候选里只有 3 个达标，全部是同一族：

### ✅ 推荐规则（样本外验证通过）

```
选股：当日三线穿阳 + 收盘破20日高 + MA89 十日斜率>0   （= 现有 A 级形态）
买入：次日开盘
止盈：盘中触及买入价 +3% 立即卖出
止损：不设个股硬止损（组合层用仓位/分散控制）
时间退出：20 个交易日收盘无条件平仓
```

| 阶段 | n | 触达胜率 | 扣成本后单笔均值 |
|---|---|---|---|
| 训练（~2026-07-06） | 538 | **86.8%** | **+0.44%** |
| 样本外（07-06 之后） | 77 | **80.5%** | **+0.32%** |

同族备选：
- `+3% / 不止损 / 10日`：训练 79.7%/+0.53%，样本外 72.7%/+0.02%（更短但更薄）
- `+5% / 不止损 / 20日`：训练 77.1%/+0.72%，样本外 68.8%/+0.33%（期望更厚、胜率更低）

**纯持有对照（次日开盘买、扣成本）**：全部信号 5日 45.2%/-0.11%、20日 37.8%/-1.81%；A级 5日 51.1%/+1.21%；**A级+上证>MA20 5日 53.0%/+1.45%、10日 53.3%/+1.83%**；A级+非涨停+粘合≤3% 20日 53.0%/+2.89%（但样本外样本少，稳健性未过）。

## 七、必须说清的风险

1. **不设硬止损是双刃剑**：推荐规则 P05 约 **-12.5%**、极端单笔可达 -20% 以上。加 -8% 硬止损后样本外均值立刻转负（-0.12%），说明正期望来自「尾部均值回归」。**实盘必须靠小仓位分散（单票 ≤1/3 试仓）+ 组合层总回撤线控制，而不是单票死扛**。
2. **样本外窗口短且环境差**：切分后仅 ~4 个月、A级样本 77 个；2026-07-06 后市场转弱，所有强势形态组合普遍衰减 10~35pp，结论需继续前向跟踪验证。
3. **90% 的统计本质**：胜率与赔率此消彼长。在未引入新信息（资金流/分时/板块联动/事件/基本面）的前提下，仅靠价量形态，「90% 且赚钱」在本数据集内不存在；能稳定 90% 的口径必然是「小止盈 + 尾部裸奔」。
4. 全部结果基于本地 320 根前复权日K、单一市场约 1 年样本，含幸存者偏差；未计涨跌停无法成交、停牌、冲击成本变化。
